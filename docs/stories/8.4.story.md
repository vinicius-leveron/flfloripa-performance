# Report Generation (PDF Export)

## Descrição

Implementar geração real de relatórios em PDF. Atualmente o endpoint `/api/reports` cria um registro no banco com `fileUrl: null` e retorna um summary JSON, mas não gera arquivo downloadable.

## Critérios de Aceitação

- [ ] Relatório semanal/mensal gera PDF com métricas consolidadas
- [ ] PDF inclui: KPIs do período, gráficos de tendência, breakdown por canal
- [ ] PDF inclui: funil de conversão, leads novos, custo por lead/ingresso
- [ ] Arquivo salvo em storage (Supabase Storage ou S3)
- [ ] `fileUrl` populado no registro do Report
- [ ] Botão de download funcional na UI de relatórios
- [ ] Design do PDF segue identidade visual (navy/orange)

## Tasks

- [ ] Escolher lib de geração PDF (react-pdf, puppeteer, ou @react-pdf/renderer)
- [ ] Criar template de relatório semanal
- [ ] Criar template de relatório mensal
- [ ] Implementar geração de gráficos para PDF (chart-to-image ou SVG)
- [ ] Configurar Supabase Storage bucket para reports
- [ ] Atualizar endpoint POST /api/reports para gerar e armazenar PDF
- [ ] Adicionar botão de download na UI
- [ ] Testar com dados reais de diferentes períodos

## Dependências

- Story 8.1 (banco configurado)
- Supabase Storage ou bucket S3
