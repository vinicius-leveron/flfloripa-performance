# Meta Ads Campaign Sync

## Descrição

Implementar integração com Meta Marketing API para sincronizar campanhas do Facebook/Instagram Ads. Atualmente as campanhas são criadas manualmente — esta story automatiza o fetch de campanhas, métricas diárias (spend, impressions, clicks, conversions), e status.

## Critérios de Aceitação

- [ ] Fetch de campanhas ativas da conta Meta Ads vinculada
- [ ] Sincronização de métricas diárias: spend, impressions, clicks, cpm, cpc, ctr, conversions
- [ ] Atualização automática de status da campanha (ACTIVE, PAUSED, COMPLETED)
- [ ] Budget e datas sincronizados da campanha Meta
- [ ] Cron job inclui sync de campanhas junto com métricas de canal
- [ ] Novas campanhas criadas no Meta aparecem automaticamente na plataforma
- [ ] Campanhas finalizadas no Meta marcadas como COMPLETED

## Tasks

- [ ] Criar módulo `src/lib/social-apis/meta-ads.ts`
- [ ] Implementar fetch de campanhas: `GET /act_{ad_account_id}/campaigns`
- [ ] Implementar fetch de insights: `GET /{campaign_id}/insights`
- [ ] Criar endpoint ou integrar no cron: sync de campanhas + métricas
- [ ] Mapear campos Meta → schema Prisma (Campaign + CampaignMetric)
- [ ] Tratar paginação da API Meta
- [ ] Testar com conta Meta Ads real

## Dependências

- Story 8.1 (banco configurado)
- Story 8.2 (infra de social APIs)
- META_APP_ID e META_APP_SECRET configurados

## Notas Técnicas

Meta Marketing API:
- Campaigns: `GET /act_{adAccountId}/campaigns?fields=name,status,objective,daily_budget,start_time,stop_time`
- Insights: `GET /{campaignId}/insights?fields=spend,impressions,clicks,cpm,cpc,ctr,actions&time_range={start,end}&time_increment=1`
