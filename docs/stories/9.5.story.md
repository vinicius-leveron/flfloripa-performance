# Form Builder - Embeddable Forms & Staff Mode

## Descrição

Criar versão embedável do formulário via iframe e modo staff para preenchimento presencial por funcionários do CIP.

## Critérios de Aceitação

- [x] Rota /embed/[slug] renderiza formulário sem layout (para iframe)
- [x] Layout minimalista para embed (sem header/footer)
- [x] API GET /api/forms/[id]/embed-code retorna código de embed (iframe e script)
- [x] Formulário funciona dentro de iframe
- [x] PostMessage notifica página pai sobre submissão
- [x] Modo staff via /forms/[id]/fill no dashboard
- [x] Staff pode preencher formulário em nome de visitante
- [x] API POST /api/forms/[id]/submit-staff processa submissão staff
- [x] Submissão marcada com accessMode: STAFF e submittedById
- [x] Contador de registros na sessão para staff
- [x] Botão "Modo Presencial" adicionado ao form builder
