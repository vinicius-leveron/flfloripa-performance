# Form Builder - Database Schema & API Foundation

## Descrição

Criar a estrutura de banco de dados para o Form Builder (FormTemplate, FormField, FormSubmission, FormFieldResponse) e implementar as APIs CRUD básicas para gerenciamento de formulários e campos.

## Critérios de Aceitação

- [x] Enums FormStatus, FieldType, FormAccessMode criados no Prisma schema
- [x] Model FormTemplate criado com campos: name, slug, title, description, status, targetStageId, sendNotification, notificationEmail, createTrelloCard, submitButtonText, successMessage, redirectUrl
- [x] Model FormField criado com campos: formId, fieldType, name, label, placeholder, helpText, required, position, validation (JSON), options (JSON), conditionalLogic (JSON), leadFieldMapping, defaultValue
- [x] Model FormSubmission criado com campos: formId, leadId, ipAddress, userAgent, referrerUrl, utmSource/Medium/Campaign, accessMode, submittedById
- [x] Model FormFieldResponse criado com campos: submissionId, fieldId, value
- [x] Relações configuradas com User, Lead, FunnelStage, Webinar
- [x] `npx prisma db push` executa sem erros
- [x] `npx prisma generate` gera cliente atualizado
- [x] API GET /api/forms retorna lista paginada de templates
- [x] API POST /api/forms cria novo template com validação Zod
- [x] API GET /api/forms/[id] retorna template com campos
- [x] API PUT /api/forms/[id] atualiza template
- [x] API DELETE /api/forms/[id] arquiva template (status: ARCHIVED)
- [x] API POST /api/forms/[id]/publish publica formulário (com validações)
- [x] API POST /api/forms/[id]/fields adiciona campo
- [x] API PUT /api/forms/[id]/fields/[fieldId] atualiza campo
- [x] API DELETE /api/forms/[id]/fields/[fieldId] remove campo
- [x] API POST /api/forms/[id]/fields/reorder reordena campos
- [x] Autenticação obrigatória para todas as rotas admin
