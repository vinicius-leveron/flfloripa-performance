# Form Builder - Field Management & Drag-and-Drop Builder UI

## Descrição

Implementar APIs de gerenciamento de campos e construir a interface de arrastar-e-soltar para criação de formulários no admin.

## Critérios de Aceitação

- [x] API POST /api/forms/[id]/fields adiciona campo
- [x] API GET /api/forms/[id]/fields lista campos
- [x] API PUT /api/forms/[id]/fields/[fieldId] atualiza campo
- [x] API DELETE /api/forms/[id]/fields/[fieldId] remove campo
- [x] API POST /api/forms/[id]/fields/reorder reordena campos
- [x] Página /forms lista todos formulários com status e contadores
- [x] Página /forms/new cria novo formulário
- [x] Página /forms/[id] exibe form builder
- [x] Paleta de tipos de campo (TEXT, EMAIL, PHONE, TEXTAREA, SELECT, CHECKBOX, DATE)
- [x] Arrastar campos para reordenar via @dnd-kit
- [x] Editor de propriedades (label, placeholder, required, helpText)
- [x] Editor de opções para SELECT
- [x] Mapeamento de campos para Lead (name, email, phone, etc.)
- [x] Preview em tempo real do formulário
- [x] Botão publicar formulário
