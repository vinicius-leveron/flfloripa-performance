# Alerts & Reports System

## Descrição

Sistema de alertas automáticos (queda de engajamento, cadência, campanha) com marcação de lido, e geração de relatórios com resumo de métricas.

## Critérios de Aceitação

- [x] Lista de alertas com severity badges (Crítico, Atenção, Aviso)
- [x] Ícones e cores por tipo de alerta
- [x] Marcação de alerta como lido via PATCH
- [x] Contador de alertas não lidos
- [x] Configuração de thresholds de alerta
- [x] Geração de relatório semanal/mensal/customizado
- [x] Resumo com totais de impressões, engajamento, reach, leads
- [x] Estado vazio com ilustração e descrição
