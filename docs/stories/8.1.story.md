# Supabase Database Setup & Migration

## Descrição

Configurar o projeto Supabase, obter connection string, executar migrations do Prisma para criar as 15 tabelas, rodar o seed com dados iniciais, e verificar que a aplicação funciona end-to-end com banco real.

## Critérios de Aceitação

- [ ] Projeto criado no Supabase (região Brasil se disponível)
- [ ] DATABASE_URL configurado no `.env` local
- [ ] DATABASE_URL configurado no Vercel (ou hosting escolhido)
- [ ] `npx prisma migrate dev --name init` executa sem erros
- [ ] 15 tabelas criadas: users, accounts, channels, posts, metrics, campaigns, campaign_metrics, funnel_stages, leads, lead_events, content_calendar_entries, alerts, reports, cadence_goals, alert_thresholds
