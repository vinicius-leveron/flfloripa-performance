# Social Media API Integration (Metrics Sync)

## Descrição

Implementar a integração real com as APIs do Instagram (Graph API), TikTok (Research API), e YouTube (Analytics API) para buscar métricas reais dos canais conectados. Os endpoints de sync atualmente são stubs que apenas atualizam o timestamp.

## Critérios de Aceitação

- [ ] Instagram: fetch de impressions, reach, engagement, profile_visits, followers_count via Graph API
- [ ] TikTok: fetch de métricas de conta via TikTok API v2
- [ ] YouTube: fetch de views, subscribers, engagement via YouTube Analytics API
- [ ] Métricas salvas na tabela `metrics` com data correta
- [ ] Endpoint `/api/channels/[id]/sync` busca e salva métricas reais
- [ ] Endpoint `/api/cron/sync-metrics` sincroniza todos os canais conectados
- [ ] Tratamento de token expirado (refresh automático quando possível)
- [ ] Tratamento de rate limiting das APIs
- [ ] Logs de erro quando API externa falha
- [ ] Canal marcado como ERROR quando sync falha repetidamente

## Tasks

- [ ] Criar módulo `src/lib/social-apis/instagram.ts` com fetch de métricas
- [ ] Criar módulo `src/lib/social-apis/tiktok.ts` com fetch de métricas
- [ ] Criar módulo `src/lib/social-apis/youtube.ts` com fetch de métricas

- [ ] Implementar refresh de token para YouTube (OAuth refresh_token)
- [ ] Atualizar endpoint sync para chamar módulos por plataforma

- [ ] Adicionar retry com backoff para falhas de rede
- [ ] Testar com conta Instagram real
- [ ] Testar com conta YouTube real

## Dependências

- Story 8.1 (banco configurado)
- Credenciais de API (Meta App, YouTube API Key, TikTok Client)

## Notas Técnicas

APIs de referência:
- Instagram Graph API: `GET /{ig-user-id}/insights?metric=impressions,reach,follower_count&period=day`
- YouTube Analytics: `GET /v2/reports?ids=channel=={channelId}&metrics=views,likes,subscribersGained`
- TikTok: `POST /v2/research/user/info/`
