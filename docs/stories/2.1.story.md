# Channel Integration & Metrics Dashboard

## Descrição

Integração com canais sociais (Instagram, TikTok, YouTube) via OAuth, dashboard com KPIs de métricas (impressões, engajamento, seguidores), gráficos de tendência e comparação por canal.

## Critérios de Aceitação

- [x] Conexão OAuth com canais (Instagram, TikTok, YouTube)
- [x] Dashboard com 4 KPIs: impressões, engajamento, seguidores, taxa de engajamento
- [x] Gráfico de tendência com filtro de período (7d/30d/90d)
- [x] Comparação de métricas entre canais conectados
- [x] Cron job de sincronização de métricas
- [x] Página de configuração de canais com status de conexão
- [x] Trends com direção (up/down/stable) e variação percentual
