# User Management & Onboarding

## Descrição

Implementar fluxo de gestão de usuários para o admin: convidar novos usuários, definir roles (ADMIN/EDITOR/VIEWER), desativar contas. Também inclui um onboarding mínimo para novos usuários configurarem seus canais na primeira vez.

## Critérios de Aceitação

- [ ] Tela de gestão de usuários acessível por ADMIN
- [ ] Listagem de todos os usuários com nome, email, role, data de criação
- [ ] ADMIN pode alterar role de outro usuário
- [ ] ADMIN pode desativar/reativar conta de usuário
- [ ] Convite por email (opcional — pode ser apenas cadastro via /register)
- [ ] Primeiro login mostra wizard de onboarding: conectar pelo menos 1 canal
- [ ] Reset de senha via email (ou link de reset)
- [ ] Validação: ADMIN não pode rebaixar a si mesmo se for o único ADMIN

## Tasks

- [ ] Criar página /settings/users (apenas ADMIN)
- [ ] Criar endpoint GET/PUT /api/users/[id] para gestão de usuários
- [ ] Implementar mudança de role via API
- [ ] Adicionar campo `isActive` ao schema User (ou soft delete)
- [ ] Criar componente de onboarding wizard
- [ ] Implementar lógica de detecção de primeiro login
- [ ] Implementar reset de senha (SendGrid/Resend ou link simples)
- [ ] Testes de permissão (EDITOR não pode acessar gestão de usuários)

## Dependências

- Story 8.1 (banco configurado)
