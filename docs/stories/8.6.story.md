# LGPD Compliance & Data Privacy

## Descrição

Implementar conformidade com LGPD (Lei Geral de Proteção de Dados) para o tratamento de dados de leads e usuários. Inclui consentimento, direito de exclusão, anonimização, e registro de operações.

## Critérios de Aceitação

- [ ] Leads podem solicitar exclusão total de seus dados (hard delete, não apenas soft delete)
- [ ] Registro de consentimento quando lead é cadastrado manualmente
- [ ] Endpoint de exportação de dados do lead (direito de portabilidade)
- [ ] Anonimização de dados de leads excluídos em eventos históricos
- [ ] Política de retenção: dados de métricas > 2 anos podem ser anonimizados
- [ ] Log de acesso a dados pessoais (quem visualizou perfil do lead)
- [ ] Aviso de cookies/privacidade na landing page (se aplicável)

## Tasks
